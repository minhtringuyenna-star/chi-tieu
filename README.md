# Chi tiêu

App theo dõi chi tiêu cá nhân, chạy trên trình duyệt (tối ưu cho iPhone). Dữ liệu lưu ngay trên máy (localStorage), không cần server.

## Tính năng
- Ghi khoản chi / khoản thu nhanh, chọn danh mục bằng icon
- Tổng quan tháng: thu, chi, còn dư, biểu đồ tròn theo danh mục
- Ngân sách (hạn mức) cho từng danh mục, cảnh báo khi gần chạm / vượt
- Lịch sử theo ngày, lọc theo loại và danh mục; sửa / xoá giao dịch
- Tự thêm, sửa, xoá danh mục; đổi icon và màu
- Nhắc ghi bù khi hôm qua chưa ghi; đếm chuỗi ngày ghi liên tục
- Sao lưu / khôi phục (file .json), xuất CSV mở bằng Excel

## Đưa lên GitHub Pages
1. Tạo repo mới trên GitHub, ví dụ `chi-tieu` (Public).
2. Upload toàn bộ file trong thư mục này vào repo (Add file → Upload files → Commit).
3. Vào **Settings → Pages**, mục *Source* chọn **Deploy from a branch**, branch `main`, thư mục `/ (root)` → Save.
4. Đợi 1–2 phút, link sẽ là `https://<tên-github>.github.io/chi-tieu/`.

## Cài lên màn hình chính iPhone
Mở link bằng Safari → nút Chia sẻ → **Thêm vào MH chính**.

## Lưu ý
Dữ liệu chỉ nằm trên trình duyệt của máy đang dùng. Nên vào **Cài đặt → Sao lưu dữ liệu** định kỳ (ví dụ cuối mỗi tháng).
